# Content page

Kestrel is an open source HTTP client library, and this is its documentation.
The writing is already done and lives as articles, each with a title, a one
sentence summary, a category, a last-updated date, an author and a body of
several thousand words with headings and code samples. There are five
categories holding about forty articles between them. A reader arrives from a
search engine on one article, needs to read it, and then needs to find the two
or three articles next to it that answer the question they actually had. So the
index has to let someone scan every category and pick, an article has to be
readable end to end, and there has to be a search box that matches titles and
summaries. Someone reading an article should be able to reach the next one in
its category without going back to the index.

Build this in the WebJs app in this directory.
