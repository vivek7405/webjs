# Dashboard

Northwind Freight moves pallets between eight regional depots. Dispatchers sit
with this screen open all day and use it to answer one question: what needs
attention right now. Each delivery has an id, an origin depot, a destination
depot, a driver, a scheduled date, a state (booked, loaded, in transit,
delivered, failed) and a pallet count. The screen must show how many deliveries
are in each state today, how the delivered count moved over the last fourteen
days, and the twenty most recent state changes with the delivery and the driver
who caused each one. A dispatcher must be able to narrow all of it to a single
depot, and must be able to open any delivery from the recent list.

Build this in the WebJs app in this directory.
