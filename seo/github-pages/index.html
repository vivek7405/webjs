What is WebJs?

WebJs is a free, open-source, full-stack JavaScript web framework built on web components. It server-renders every page and component to real HTML, needs no build step or bundler, and runs on Node 24+ or Bun.

You write pages, layouts, and components as plain files. WebJs serves that source to the browser exactly as you wrote it, so the code you read is the code that runs. Content reads and forms submit before any script loads, and JavaScript is added only where an interaction actually needs it.

Install it

npm create webjs@latest my-app
cd my-app
npm run dev

The scaffold ships routing, a database layer, and a styled layout, so you start from a production-shaped app rather than an empty directory.

What WebJs gives you

  • Web components, server-rendered. Standard custom elements whose render() runs on the server, so the markup is in the HTTP response before any script loads. Light DOM by default, so global CSS and Tailwind apply directly.
  • File-based routing. A page.ts is a route, a layout.ts wraps everything under it, and a route.ts is an HTTP handler. Dynamic segments, route groups, error boundaries, and loading states follow the folder structure.
  • Server actions with real types. Export an async function from a .server.ts file and import it straight into a component. The import becomes a typed RPC call, and the server source never reaches the browser.
  • Batteries included. Sessions, authentication, caching, rate limiting, file storage, and WebSockets ship in the box, sharing one pluggable store that a single call moves onto Redis.
  • TypeScript with nothing to compile. Types are stripped at request time by Node 24+ or by amaro on Bun, so what you read in the editor is what runs in the browser.

Other projects called WebJS

The name is shared. If you arrived looking for one of these, they are not this project.

whatsapp-web.js (wwebjs)

An unofficial Node.js library for building WhatsApp clients and bots. Unrelated to this framework.

WebJS for Java

An older framework aimed at letting Java developers build web applications without combining many technologies. Last published in 2013 and no longer active.

webJS toolkit

A small client-side JavaScript toolkit that compiles HTML templates into reusable JavaScript. A browser library rather than a full-stack framework.

Frequently asked

Is WebJs free to use?

Yes. WebJs is free and open source under the MIT license, developed in the open on GitHub. There is no paid tier and no license key.

Does WebJs need a build step?

No. Source files are served directly as native ES modules, and TypeScript is stripped at request time, so there is no bundler, no compile output, and no watch process to keep in sync.

Does a WebJs app work without JavaScript?

Yes, for everything that does not require interactivity. Pages and components are server-rendered, so content reads, links navigate, and forms submit with JavaScript disabled.

What can you build with WebJs?

Full-stack web applications with server-rendered pages, routing, server actions, authentication, and a database layer. It also runs backend-only as an HTTP and JSON API framework.
